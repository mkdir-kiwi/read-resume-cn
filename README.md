# read-resume-cn
打开二十个网页，读到一半突然有事；关掉吧，怕忘记看到哪；留着吧，又舍不得关电脑。
「继续读 · Read Resume」是一款轻量的 Edge 浏览器扩展，帮你保存一组网页，并在下次打开时接着之前的位置阅读。查资料、读教程或同时浏览多篇文章时，只需点击网页角落的悬浮球，就能保存当前网页、选定网页，或整个窗口的页面，把暂时没看完的内容整理成阅读项目。
重新打开浏览器后，从历史项目中选择恢复，工具便会在新窗口打开这些网页，并尝试定位到上次阅读的段落或滚动位置，减少重新翻找的麻烦。项目支持自定义名称、历史管理和备份导入导出，无需注册账号，存档数据保存在本机。
当前版本优先支持普通文章、博客和文档页面；动态网页的位置恢复可能受内容变化影响。
「继续读」希望让每一次暂时离开，都能有一个方便回来的入口。
